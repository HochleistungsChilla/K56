# DDC profiles

Eight headphone-correction profiles ship unchanged so the app has a working
set on first start.

## Source

<https://github.com/syntaxticsugr/ViPER4Android-Presets> (release v4.0.0,
GPL-3.0). That project redistributes DDC files as-is from their original
authors.

`ViPER4Android-Presets-v4.0.0-Recommended.zip`; no coefficient was edited.
