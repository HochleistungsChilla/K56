# K56 — Branding

## Name

**K56** — Anspielung auf den 56k-Modem-Standard von 1998. Kurz, technisch,
augenzwinkernd. Gesprochen „K-fifty-six“.

- Claim: **„56k für die Ohren.“**
- Domain: **k56.wtf** (verfügbar geprüft, noch nicht registriert)
- Alternativ-Domain: `56k.wtf` (ebenfalls frei)

## Gestaltung

- **Monochrom** ist der Name des dunklen Standard-Themes (Amber/Grün auf
  Schwarz, CRT-Anmutung).
- **ATDT** ist das Easter Egg: der alte Hayes-Wählbefehl (`ATDT…`) im
  About-/Debug-Bereich. Kein UI-Element, das erklärt werden muss.

## Warum nicht …

- **Symfonium**: fremde Marke, wird nicht verwendet.
- **Resona/Nadelton**: frühere Arbeitstitel, verworfen.
- **Monochrom** als App-Name: zu generisch und vielfach belegt, deshalb nur
  Theme-Name.
- **ATDT** als App-Name: starker Nerd-Witz, aber schlecht aussprechbar und
  schlecht suchbar.

## Konsequenz für Code und Repo

- Android-Package: `app.k56.player`
- Repo: `k56`
- App-Label: `K56`
- Keine fremden Logos, Assets oder Namensbestandteile.
