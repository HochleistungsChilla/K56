# K56 — Branding

## Name

**K56** — a nod to the 56k modem era of 1998. Short, technical, tongue-in-cheek.
Pronounced “K-fifty-six”.

- Tagline: **“56k for your ears.”**
- Domain: **k56.wtf** (checked as available, not registered yet)
- Alternative domain: `56k.wtf` (also free)

## Design

- **Monochrom** is the name of the default dark theme (amber/green on black,
  CRT feel).
- **ATDT** is the easter egg: the old Hayes dial command (`ATDT…`) in the
  about/debug area. Not a UI element that needs explaining.

## Why not …

- **Symfonium**: someone else's trademark, not used.
- **Resona/Nadelton**: earlier working titles, discarded.
- **Monochrom** as the app name: too generic and widely used, so it is only the
  theme name.
- **ATDT** as the app name: a strong nerd joke, but hard to pronounce and hard
  to search for.

## Consequences for code and repo

- Android package: `app.k56.player`
- Repo: `k56`
- App label: `K56`
- No third-party logos, assets or name fragments.
